# AI 脱敏助手 · 演示版

面向高敏感业务场景的 AI 脱敏与还原流程演示：把敏感文件交给 AI 之前先在本地脱敏，拿到 AI 的回复后再一键还原成真实信息。

**在线体验：** https://oliverbliang.github.io/ai-desensitize-demo/

## 演示流程

1. **选择文件**：律所案件说明（PDF 扫描件，模拟 OCR）、药物研发 PK 实验数据（XLSX）、项目合同（DOCX）
2. **脱敏级别**：L1 基础 / L2 标准 / L3 增强（推荐发给 AI）/ L4 彻底，也可以按信息类型自定义；原文和脱敏版左右对照
3. **发送给 AI**：模拟对话，AI 只能看到脱敏版
4. **还原结果**：AI 回复中的占位符换回真实信息，AI 新算出的数值按缩放系数反算；文件逐字还原校验

## 说明

- 纯前端单文件（`index.html`），无依赖，所有处理都在浏览器本地完成
- 识别为规则 + 上下文模拟的“语义识别”，AI 回复为预置模板，仅用于演示产品流程
- 所有示例数据（人名、机构、证件号、实验数据）均为虚构
